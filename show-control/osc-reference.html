OSC addresses

This is the complete list of OSC addresses Earshot accepts. It is the same table as docs/osc.md in the repository, which a test checks against the engine, so the spellings here are exactly what Earshot accepts.

Spellings are exact. There are no aliases. /earshot/safe, /earshot/arm and /Earshot/armed/off do nothing.

Everything here applies only when OSC input is on. It is off by default. See OSC input for how to turn it on, what the levels mean and which devices are allowed.

How to read the table​

ColumnMeaning
AddressWhat to send. <channel> and <automation> are placeholders: see below.
ArgumentsWhat to send with it. "none" means the message must have no arguments: an unexpected argument is refused ("takes no arguments").
ReplyWhat Earshot sends back to the sender, if anything.
LevelThe lowest setting of What incoming OSC may do that allows it. Any device works at every level, from any sender. Trigger needs Trigger automations or higher, and a sender on the allowed list (or this computer). Full needs Full control, including arming, and a sender on the list.
TransportUDP, TCP, or both. TCP is SLIP-framed (OSC 1.1).

/earshot/armed appears twice on purpose. With false, 0 or "off" it makes the show Safe, from any device. With true, 1 or "on" it arms, and that needs the Full level, an allowed device and TCP.

Placeholders​

<channel>​

A channel can be named three ways:

WayExampleNotes
Its nameShow CallerAny case.
Its short nameshow-callerThe Slug box in the channel's settings (Setup, Channels).
Its position11 is the first channel in show order.
  • As an argument (/earshot/channel/select, /earshot/channel/send, /earshot/channel/mark, /earshot/channel/clear) all three work. A position can be sent as a number or as a string.
  • Inside an address (/earshot/channel/<channel>/select and the others) use the short name or the position, for example /earshot/channel/show-caller/select or /earshot/channel/1/select. An OSC address cannot contain a space, so a name with a space in it has to go as an argument instead.

<automation>​

An automation's id, its short name or its name. Inside an address use the short name, for example /earshot/automation/go-cue/trigger. As an argument (/earshot/automation/trigger) the name works too, for example the string Go cue.

The short name is the Short name in the automation editor. /earshot/automation/list replies with every automation's short name.

What each group does​

Safe and Armed​

/earshot/armed/off and /earshot/armed with false make the show Safe. They work from any device, over UDP or TCP, at every level, and are never rate-limited.

/earshot/armed/on and /earshot/armed with true arm the show. They need the Full level, an allowed device, and TCP. Over UDP they are refused, whatever else is set.

A packet or bundle that contains a Safe never arms. See OSC input.

Ping and version​

/earshot/ping is answered with /earshot/reply/pong and the same arguments you sent. /earshot/version is answered with /earshot/reply/version and the app version as a string. Both work from any device. Use them to check a cable, a port number or a firewall.

Typed lines, alerts and markers​

  • /earshot/channel/<channel>/send and /earshot/channel/send put a typed line into a channel, as if someone had typed it in the Feed. Typed lines never fire phrase automations, however they arrive.
  • /earshot/flash flashes a message across every screen. The optional second argument is a colour, such as #ff4639. If the optional third argument is true (or 1), the message stays until an operator presses Acknowledge.
  • /earshot/marker/add adds a marker to the session at this moment, with the label you send, if any. See Archive and search.

Automations​

  • /earshot/automation/trigger and /earshot/automation/<automation>/trigger run one automation, like pressing Run now. While the show is Safe this is a dry run: Activity shows what would have been sent, and nothing is sent.
  • /earshot/automation/list replies with one string per automation: its short name.
  • An automation limited to named people never fires from OSC, because there is no voice. See Automations limited to people.

Clearing a transcript​

/earshot/channel/<channel>/clear and /earshot/channel/clear clear a channel's transcript (or every channel's, if you send no channel). The lines of the current session are deleted. Past sessions are not touched. They need the Full level.

danger

Clearing a transcript also makes its saved audio unreachable at once, and deletes the files. See Replay a line's audio.

Mark read​

mark means mark read: /earshot/channel/<channel>/mark and /earshot/channel/mark clear the unread counts. They do not add a marker. To add a marker, use /earshot/marker/add.

Any other address​

An address that does not start /earshot/ is a plain address. It fires the automations whose OSC trigger matches it. That needs the Trigger level and an allowed device, over UDP or TCP.

For example, an automation whose trigger is An incoming OSC message with the pattern /cue/{n}/go fires when a console sends /cue/7/go, and its actions can use {{capture.n}}, {{osc.address}} and {{osc.args.0}}. See Triggers and Variables.

An incoming address may not itself contain pattern characters (*, ?, [, ], {, }): one message does at most one thing.

View controls change the host computer's own window only​

These addresses are view controls:

  • /earshot/channel/next, /earshot/channel/previous
  • /earshot/channel/select, /earshot/channel/<channel>/select
  • /earshot/channel/mark, /earshot/channel/<channel>/mark
  • /earshot/scroll/up, /earshot/scroll/down, /earshot/scroll/live
  • /earshot/font/up, /earshot/font/down

They are carried out by the Earshot window on the host computer (and by a browser open on that same computer). They are never sent to phones, tablets or other computers. They change what is shown, not the show.

On the host's window:

  • Select channel changes the Feed's filter if one is set. It shows that channel in Focus. If the window is on the Feed with all channels showing, or on Lanes, it switches to Focus on that channel.
  • Next and previous step through the channels in show order and wrap round.
  • Scroll up and down move the Feed one page. Scroll to live returns to the newest line.
  • Font up and down change the text size on that window.
  • Nothing happens while someone is in Setup, Automations, Archive or Activity. A cue never throws someone out of an editor.

Where else to find this list​

On a running host, the API reference (Setup, Show control, top right, or /docs) includes the same OSC list. See HTTP API.
