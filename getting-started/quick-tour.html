Get started with Earshot

Start here if you are setting up Earshot for the first time. You will install the app on one computer, turn speech into a transcript, and open that transcript on a crew member's phone. Everything is done through the app and your computer's usual installation screens.

Before you start​

Have these ready:

  • The computer that will run Earshot, connected to power. This is the host; keep it awake while Earshot is listening.
  • An audio input. Your computer's built-in microphone is enough to try Earshot. For a show, connect the audio interface carrying your comms inputs.
  • Internet access to download Earshot and its recommended speech models (about 488 MB). Once installed, local speech recognition works offline.
  • A shared network if you want the crew to read along on other devices.

Check supported systems and known limits before choosing a show computer. Earshot has been tested on Apple Silicon Macs. Windows and Linux builds passed a headless demo startup smoke test, but their installer interfaces and desktop windows have not been tested.

1. Install and open the app​

  1. Open Earshot Releases. Choose the package for your computer under Assets, rather than a Source code archive.
  2. Install it using your computer's usual installer. On a Mac, open the disk image and drag Earshot to Applications.
  3. Open Earshot from Applications, the Start menu or your application launcher.

See Install and update for package availability and installation details. Downloads are available for macOS Apple Silicon, Windows x64 and Linux x86_64. Check the chosen release’s notes for the packages it includes.

The Earshot window gives you admin access automatically. You can set up the host right there.

2. Start the setup assistant​

On a new show, Set up Earshot opens automatically. Press Get started.

If you have already closed it, open Setup and press First-time setup… at the bottom of the section list.

Screenshots show a sample show. Your devices and channels will have their own names.

The assistant has four steps: Welcome, Models, Inputs and Done. Follow them in order for your first setup.

3. Download the speech models​

In Models, press Install all recommended. Wait until Silero VAD and Parakeet TDT both show Installed, then press Next.

The sample screen illustrates the download controls. Use the models marked Recommended in your app.

These downloads happen once. They let Earshot recognise speech on this computer, without choosing a cloud service. Optional translation and voice-recognition models can wait.

If a download fails, check the internet connection and retry it under Setup → Models. See Speech models for more help.

4. Choose your first audio input​

In Inputs:

  1. Choose your microphone or audio interface under Audio device.
  2. Tick the input you want to try. For a built-in microphone, start with input 1. For an interface, use the input carrying your test microphone or comms line.
  3. Under Name channels, enter a name such as Test or Comms.
  4. Press Create. The button includes the number of channels you selected.
  5. Allow microphone access if your computer asks. Earshot needs this permission for audio interfaces as well as microphones.
  6. Press Next, then Go to the Feed.

The sample screen shows a two-input device. Tick only the inputs you intend to listen to.

If your interface is missing, check that it is connected and press Rescan devices. You can add more inputs later under Setup → Patch; see Patch inputs.

5. See your first transcript​

  1. Check that the header says Live and Safe.
  2. Speak a short sentence into the chosen microphone or comms input, then pause.
  3. Watch the channel's level meter. It should move while you speak.
  4. Read the line in the Feed. Draft words may change before the line settles.

You now have a working local transcript. Speech recognition can make mistakes, so try the names and phrases your crew uses before a show.

If the meter does not move, check the input and your computer's microphone permission. If the meter moves but no words appear, check that both recommended models show Installed under Setup → Models. Troubleshooting covers the next checks.

Open Setup → Channels to give the channel a useful name and colour. Add your remaining comms inputs under Setup → Patch, and test each one in the same way.

6. Let the crew read along​

Before sharing, open Setup → Access and choose who can connect. Earshot starts in Open mode, where anyone on the network can operate the show, including arming it. Choose Password or Personal links to control access; personal links let you give someone a read-only Viewer role.

  1. Connect the crew member's phone or laptop to the same network as the host.
  2. Give them Address for the crew from Setup → Access, together with the password or personal link your chosen mode requires.
  3. Open it in their browser and sign in if prompted.
  4. Say another test sentence and check it appears on both devices.

The crew does not need to install the desktop app. Keep Earshot running on the host while they read. See Who can connect for access modes and Earshot on a phone for phone setup.

7. Read comfortably and save your setup​

  • Use Feed for one combined timeline, Lanes for channel columns, or Focus for a large view of one channel.
  • Open Display on this device from the header to choose a theme and text size. Each crew member can choose their own display settings.
  • Under Setup → Show file, name the show and export a copy of its settings. See Show files.

Your normal show and transcript are saved on the host. Closing the desktop window on macOS or Windows leaves Earshot running. To stop listening, choose Quit from its tray or menu bar icon, or press Cmd+Q on a Mac. Open the app normally next time to continue using your saved setup.

Ready for a show​

You have completed the basic setup when:

  • Every input you need has a moving meter and produces readable text.
  • A crew device can connect using the access mode you chose.
  • The host stays awake and the header shows Live and Safe.

Work through the before-show checklist before using Earshot in production. Limits and known behaviour explains what has been tested.

Automations are optional. When you are ready to explore them, start with Safe and Armed, then Build an automation and Test it.
