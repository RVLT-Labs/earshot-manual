First-time setup

When an admin opens Earshot on a show with no channels, the Set up Earshot box opens by itself. It takes a few minutes and gets you from nothing to a transcript: install a speech model, then choose the inputs to listen to.

Who sees it

The desktop app gives you admin access automatically. See Get started with Earshot for the complete path from installation to your first transcript. You can reopen the box any time from Setup, button First-time setup… at the bottom of the section list.

It has four steps: Welcome, Models, Inputs, Done. Every step can be skipped and redone later under Setup. Skip setup closes the box at any point.

Step 1: Welcome​

The mock host with an empty show. Not a real show.

The box says what Earshot is about to do: "Earshot listens to your intercom and talkback inputs, turns speech into text on this machine, and shows every channel on one screen that the whole crew can open."

Press Get started.

Step 2: Models​

Earshot does not come with its speech models. You download them once, then they work offline.

The mock host. Its list of models is invented: the real names and sizes are on the Speech models page.

  1. Press Install all recommended, or press the download button beside each model you want.
  2. Wait for each row to show Installed. The big one is about 487 MB.
  3. Press Next.

You need internet for this. If you are not on a connection you trust to finish a 500 MB download, press Next and do it later under Setup, Models. Until a speech model is installed, channels cannot transcribe.

Step 3: Inputs​

This step is the Patch screen inside the box.

The mock host and its made-up audio devices.

  1. Under Audio device, choose your interface.
  2. Tick the inputs that carry comms. Each tick becomes one channel.
  3. Type a prefix under Name channels if you want one. The input number is added, for example "USB 1".
  4. Press Create (the button reads "Create 4 channels" and so on).
  5. Press Next. If you made no channels, the button reads Skip for now.

You can rename the channels and give them colours afterwards. Do not spend time on it here.

Step 4: Done​

The last step reads You are ready, and says how many channels are set up, or "No channels yet. You can add them any time under Setup."

It also reminds you of the one thing that most often goes wrong: "The first time a channel starts, your operating system may ask for permission to use the microphone. Choose Allow, or Earshot will hear silence."

Press Go to the Feed.

Then check it works​

  1. The header says Live.
  2. In the channel list, each channel's level meter moves when someone speaks on it.
  3. Say a test line on each channel and read it in the Feed.

If no text appears, go to Troubleshooting. It lists the checks in order.

The rest of the setup, in a sensible order​

The box covers the minimum. For a real show, work down this list. Each line is a section of Setup.

OrderSetup sectionWhat to do therePage
1ModelsDownload the recommended models. Pick the Default speech model.Speech models
2PatchChoose the audio device and tick inputs.Patch inputs and make channels
3ChannelsRename, colour and tune each channel.Channels
4GroupsPut channels in folders such as Stage and Audio.Groups
5AccessDecide who can connect. Do this before the crew arrive.Who can connect
6GlossaryAdd the names, songs and gear the recogniser gets wrong.Glossary
7PeopleOptional. Name detected voices on a shared channel, or learn one deliberately.People and voices
8Cloud & audioOptional. Saved-audio limits, translation, cloud speech.Cloud and audio
9Show controlOnly if a console or controller will talk to Earshot.Consoles and controllers
10Show fileName the show. Export a copy when you are happy with it.Show files

Then build your automations, if you use them, and run the before-show checklist.
