Install and update

Install Earshot on the host computer connected to your audio inputs. Crew members use a browser on the same network. They do not need a copy of the desktop app, a repository checkout or developer tools.

Download Earshot​

Open Earshot Releases and choose a release. Read its release notes for supported systems, known issues and any upgrade instructions, then download a package from Assets that matches your operating system and processor. GitHub's Source code archives contain only the downloads repository's files; they are not installers or the application source.

Release downloads are available for macOS Apple Silicon, Windows x64 and Linux x86_64. Check each release’s asset list: a new version may appear for one system before the others. The installers are unsigned and the macOS app is not notarised. Each platform’s headless host has passed a demo startup smoke test; Windows and Linux installer interfaces and desktop windows have not been tested. There is no Intel Mac package.

v0.5.0 is macOS Apple Silicon only. Windows and Linux builds are on hold; their earlier packages remain on the release pages.

Install the desktop app​

Use only a package listed for your system in that release's notes.

PackageInstallation
macOS .dmgOpen the disk image, drag Earshot to Applications, then eject the disk image. Open Earshot from Applications. The published Mac package is for Apple Silicon only.
Windows installer (.msi or .exe)Run the installer and follow its prompts, then open Earshot from the Start menu.
Linux .deb or .rpmInstall with your system's package manager, then open Earshot from the application menu.
Linux .AppImageGive the downloaded file permission to run as a program, then open it. Follow the release notes for any runtime dependencies.

The current macOS bundle configuration requires macOS 11 or newer. The release notes should confirm the requirements for each published build. Unsigned builds may prompt an operating system warning on first launch. Check that the download came from the Earshot repository before choosing to open it.

First launch​

  1. Open Earshot. Its window signs you in as an admin automatically.
  2. Allow microphone access when the operating system asks. If you previously denied it, enable Earshot in the system's microphone privacy settings.
  3. In the first-time setup, install the recommended Silero VAD and Parakeet TDT models (about 488 MB together). Internet is needed for this download; speech recognition then works offline.
  4. Choose audio inputs and create channels under Setup → Patch.
  5. Say a test line and check the transcript. Keep the show Safe while setting up automations.
  6. Under Setup → Access, choose who may connect and give the crew Address for the crew. Keep the host awake and connected to the show network.

Continue with Get started with Earshot for the complete walkthrough. Earshot starts in Open access mode, where anyone on the network can operate the show, including arming it. Set access before using a shared network.

The desktop app normally listens on port 4780 and chooses another port if that one is busy. On macOS and Windows, closing the window leaves Earshot running; use Quit from the tray or menu bar icon to stop it.

Update Earshot​

Earshot checks GitHub Releases shortly after launch and every six hours. To check yourself, choose Check for Updates… from the tray icon's context menu, or the Earshot menu on macOS.

When an update is available:

  • Update now downloads and verifies it, stops transcription, installs it and restarts Earshot. Transcription keeps running during the download. Choose a quiet time to install.
  • Not now postpones reminders for this version until you next open Earshot.
  • Don't remind me for this update skips automatic reminders for that version. A newer version can still prompt you, and Check for Updates… still shows the skipped version.

In-app installation works on macOS, Windows and Linux AppImage installations. Linux DEB/RPM installations use the package manager. Older Earshot versions without Check for Updates… need one manual update to a version that includes it.

You can also update manually:

  1. Read the new release's notes for compatibility and migration instructions.
  2. Export your show from Earshot. For a complete backup, quit Earshot and copy its data folder as well: a show export does not include history, saved audio, secrets or learned voices. See Privacy and stored data.
  3. Download the new package from Releases, quit the running app, and replace or update it using the same installation method.
  4. Open Earshot, check your channels and model status, and test your setup while Safe before returning to a show.

Do not delete the data folder to update the app. Models and show data are stored separately from the application. Follow release-specific instructions before using an older version with newer data.

Headless hosts​

For rack computers managed by an administrator, see the headless host reference. The desktop app is the setup path for this guide.

Remove Earshot​

Quit Earshot, then remove the application using your operating system's usual method. The separate data folder contains transcripts, show settings, downloaded models and any saved audio; removing the application does not clear it. See Privacy before deleting data you may need.
