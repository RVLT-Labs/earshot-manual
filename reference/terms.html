Words used in this manual

Plain definitions, in alphabetical order. Each links to the page that covers it properly.

A to C​

Action. One thing an automation does when it fires: send OSC, send MIDI, make a web request, flash an alert, add a marker, and so on. An automation has a list of actions, run in order. See Actions.

Activity. The live log of what came in, what went out and what every automation did or would have done. It is where you look to find out why a cue did or did not fire. See Run now, the Test bench and Activity.

Admin. The role that can change everything, including Setup. The desktop app's own window is an admin. See Roles.

Armed. The state in which automations that match really send their cues. Shown in red, as ARMED. The opposite of Safe. See Safe and Armed.

Automation. A rule: a trigger, optional conditions, and a list of actions. "When the show caller says 'go cue' and a number, send that cue to the lighting desk." See Building an automation.

Behind. A channel badge meaning transcription is running late on that channel. Every line is still written down, but later than usual, and drafts stop until it catches up. See Badges and marks.

Bonjour. The way computers announce themselves on a local network (also called mDNS). Earshot uses it so other Earshot computers can find this one. See Network.

Channel. One source of speech that Earshot listens to and writes down: usually one audio input carrying one comms line. A channel can also be a recording played in as if live (a simulator), a typed-text-only channel, or a channel shown from another Earshot computer. See Channel settings.

Clip. The saved audio behind one spoken line, on a channel with Keep audio for replay on. See Replay a line's audio.

Cloud speech. Sending one channel's audio to an outside company (Deepgram) to be transcribed, instead of doing it on the host. Off unless you choose it for a channel and confirm. See Cloud & audio.

Condition. An extra check on an automation ("Only if"): the channel, the group, the person, the time of day, or a flag. All conditions must be true for the automation to fire.

Cooldown. How long an automation ignores its trigger after it fires, so that a repeated call does not send the cue twice. A new automation has 2 seconds.

D to G​

Demo. A host started in demo mode plays a scripted, made-up transcript, needs no models or audio hardware, and does not touch your own data. The header says Demo. See Quick tour.

Destination. A named place OSC is sent to: a lighting desk, a video server, a QLab machine. It has a name, an address, a port and a protocol.

Draft line. A line shown in soft grey while the person is still talking. Its words can change. Also called a partial. See The screen at a glance.

Dry run. An automation that matched but sent nothing, because the show was Safe (or because the test bench was used, which is always a dry run). Activity marks it Dry run and says what would have fired.

earshotd. The host program with no window, for a rack machine. See earshotd.

Final line. A line whose text has settled, because the person stopped speaking. Shown solid. Glossary corrections, names and cues set to "Final text" all wait for it.

Firing. One occasion on which an automation's trigger matched, with the result of each of its actions. A firing is either live (really sent) or a dry run.

Flag. A named on/off switch that one automation can set and another can check. Used for things like "we are in act two".

Glossary. Your list of words Earshot often mis-hears (names, songs, gear), each with the right spelling and the ways it tends to come out. It corrects what people read. It never changes numbers, and never changes what automations hear. See The glossary.

Group. A named folder of channels, like Stage or Audio. The Feed and Lanes can filter or arrange by group. Groups are only edited in Setup. See Groups.

H to M​

Host. The one computer that runs Earshot: it has the audio inputs, runs the speech models, keeps the transcript and serves the screens. Everyone else is just a browser looking at it.

Invite. A QR code (and link) that lets one person join once. It runs out after 10 minutes. Once used, it becomes a personal link. See Invites and personal links.

Line. One stretch of speech, or one typed message, on one channel.

Link code. What one Earshot computer needs to read another's shared channels, when that other computer asks for a sign-in. It is an ordinary viewer invite of the other computer, so treat it like a password. See Showing another Earshot computer's channels.

Linked channel. A channel that comes from another Earshot computer. Read-only, text only, and its lines never fire automations here.

Marker. A labelled point on a session's timeline, like "Act two, cue 42". See Archive, search and export.

MIDI. A long-established way for music and show equipment to send short control messages (notes, controllers, program changes). Earshot can send MIDI as an action and be triggered by it. See MIDI.

Model. A downloaded file that does one job on the host: finding speech in audio, turning speech into words, recognising voices, or translating between two languages. See Models.

O to R​

Operator. The role that can arm the show, make it safe, run automations and add markers, but cannot change Setup. See Roles.

OSC. Open Sound Control: the network message format most lighting desks, sound desks and playback systems use for remote control. An OSC message is an address like /eos/cue/42/fire with optional values. Earshot sends OSC as an action, and can be controlled by it. See OSC addresses.

Patch. Choosing which inputs of an audio device Earshot listens to. Each ticked input becomes a channel. See Patch and channels.

People. The crew members Earshot knows by voice. Each has a name, a colour, and (once learned) a voice. See People: recognise voices.

Personal link. A web address that signs in one person, with a role you chose. You can revoke it without affecting anyone else.

Phrase. The words a spoken-phrase automation listens for, for example go cue {number}. The part in braces stands for one spoken word, which the actions can then use.

Role. Viewer, operator or admin. See Roles.

Run now. Running one automation by hand from the Automations list. A dry run while Safe; it asks before sending while Armed.

S​

Safe. The state in which automations that match are only logged as "would have fired". Nothing is sent. Earshot starts Safe, and Safe always wins over Armed.

Serving host. When two Earshot computers are linked, the one that has the channel and shares it.

Session. One continuous run of the transcript. Every time Earshot starts it begins a new session. The Archive lists them.

Show. Everything you set up: channels, groups, automations, destinations, glossary, people and settings.

Show file. The show saved as one file (ending .earshot.json), so it can be carried to another computer. It holds no passwords, keys, link codes, learned voices or transcript. See Show files.

Simulator. A channel that plays a recording (a WAV file) as if it were a live input. Good for rehearsing automations without a crew.

"Sounds like". In the glossary, the wrong spellings a word tends to come out as. Only the spellings you list are replaced.

T to W​

Test bench. A screen where you type a phrase and see which automations would fire and what each would do. Always a dry run.

Trigger. What sets an automation off: a spoken phrase, an incoming OSC message, an incoming MIDI message, a web request, a channel's health, or nothing but a manual press. See Triggers.

Typed line. A line someone typed into a channel instead of saying it. It carries a Typed badge and never fires a phrase automation.

Utterance. The technical word for a line: one stretch of speech from when the person starts to when they stop. You will meet it in the API and in JSON exports.

VAD. Voice activity detection: deciding when someone is speaking, so that only speech is sent to the recogniser. Earshot uses a small model (Silero VAD) for it. The channel settings under Advanced: speech detection adjust it.

Viewer. The role that can read, type where a channel allows it, and replay saved audio, but cannot arm or run anything. See Roles.

Voice. What Earshot learns about how a person sounds, so it can put their name on their lines. Learned voices never leave the host.

Webhook. A web address that fires one automation when something calls it. The address is a secret: whoever has it can fire that automation, though it still obeys Armed and Safe. See Triggers.
