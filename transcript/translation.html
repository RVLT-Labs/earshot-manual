Read in another language

Each person can choose one language to read the transcript in. The lines are translated on the host and shown in that language, with the original underneath. It is set per device, so a Spanish-speaking crew member can read in Spanish while the stage manager beside them reads the original.

danger

Translation is a reading aid, never a cue call. Show jargon is often mistranslated. In testing, "Sound cue 7, go." came out in Spanish as "Suena a señal 7, vamos.", and "kick drum" as "tambor de patada". Do not call a cue, or act on one, from translated text. Read the original line beneath it.

Every role can choose a language for themselves. Setting up what the host can translate into needs an admin.

Switch it on​

  1. Press the display button in the header (the "Aa"). It opens Display on this device.
  2. Under Read in, choose a language, for example "español (Spanish)". Original switches translation off.
  3. Close the menu. The display button now shows the language code (ES), so you can tell at a glance that you are reading a translation.

"Lines show in this language, with the original beneath. Only for this device." Your choice is kept on this device.

The first time a device opens a transcript view on a host that can translate, a hint under the header says "Read in another language: open Display", with Open Display and Dismiss.

The mock show read in Spanish. The mock host does not really translate: some lines carry a stand-in "[es]" in front of the English. A real host shows a real translation there. Not a real show.

What you see on a line​

On the lineWhat it means
The translation, with Original and the original words beneath itThe line was translated.
The original, with Translating… beneath itThe translation is on its way. It can take up to 10 seconds.
The original, with Not translated beneath itNo translation arrived in time, or the line is in a language Earshot cannot translate from. The line stays in the original.
The line once, with nothing beneathThe line is already in your language.
  • Only finished lines are translated. A draft shows as heard until it settles.
  • Only new lines are translated. Under the menu Earshot says: "Translating new lines into Spanish. Earlier lines may stay in their original language. Lines in a language Earshot cannot translate from stay in the original."
  • Screen readers read the translation, or the original if none arrived in time, never both.
  • Earshot holds the space for a translation before it arrives, so lines do not jump as you read.

The rules​

  • One language at a time for a viewer. Operators and admins can hold more, up to the host's limit. That limit is Languages at once under Setup, Cloud & audio. It starts at 4, and 0 turns translation off. Everyone's choices share it.
  • Only while you are on Feed, Lanes or Focus does Earshot ask the host to translate for you. Lines that arrive while you are elsewhere (in the Archive, say) are not translated for you. The menu says so: "The host is asked while you are on Feed, Lanes or Focus."
  • Automations never see a translation. They hear what was said. A cue cannot be fired, or missed, because of a translation.

Which languages appear in the menu​

Only languages the host can translate into:

  • the target of each translation model installed on the host (pairs read "English to Spanish", so that one offers Spanish), or
  • any common language, if the host uses a cloud translator.

With nothing set up, the menu says "The host has no translation set up yet. An admin can add a translation model in Setup, under Models."

When the host says no​

The host can refuse a language. Earshot shows the host's own sentence. Under the header a bar reads, for example, "Can’t read in Italian." then the reason, then "Showing the original.", with Dismiss. In the display menu the same reason is followed by "Reading in the original."

The two reasons you may see:

The host saysWhat to do
"Nothing can translate into Italian here: install a translation model into Italian in Setup → Models, or set up a cloud translator."Ask an admin to install a pair that ends in that language, or to choose a cloud translator.
"Only 4 languages can be translated at once (…)"Too many different languages are in use across the crew. Someone switches back to Original, or an admin raises Languages at once.

If the host cannot be asked at all, you see "Could not ask the host about translation." and "Your language is kept, and Earshot will try again." Your choice is not lost.

Setting it up (admins)​

There are two ways for a host to translate. Both are set on the host, not on the reader's device.

Translation models on this computer​

Text never leaves the host. Download pairs under Setup, Models. They are listed as pairs, "English to Spanish". See Models.

  • German to English and English to Spanish have been run. German to Spanish works by way of English.
  • Every other pair in the list is an untested download. Its description starts "Untested.".
  • Each loaded pair uses about 330 MB of memory.
  • Translation models have been built and run on an Apple Silicon Mac only.

A cloud translator​

Under Setup, Cloud & audio, Translate with has three cards:

CardWhere the text goes
This computer (the default)Nowhere. Text never leaves.
DeepLThe text of each translated line goes to DeepL, outside the building. Needs a key.
ClaudeThe text of each translated line goes to Anthropic, outside the building. Needs a key.

Choosing DeepL or Claude asks first ("Translate with DeepL?"). Audio is not sent, only the text of lines being translated. If DeepL fails, the models on this computer are used. Neither service has been tried with a real key in this build, so try one before you rely on it.

A reader on a host that uses a cloud translator is told so in their own display menu: "The host sends the text of each line to DeepL to translate it."

The keys, the confirmation and the status counters are described in Cloud & audio. What leaves the building, and when, is in Privacy.

A worked example: a Spanish-speaking deck crew​

The mock show's deck-right crew read Spanish more easily than English. The show is called in English.

The admin, once, before the show:

  1. Setup, Models. Find the pair English to Spanish and press Download. This one has been run.
  2. Setup, Cloud & audio. Leave Translate with on This computer. Check Languages at once is at least 1.

Each crew member, on their own phone:

  1. Open the display button. Under Read in choose "español (Spanish)".
  2. Go to Lanes or Feed. New lines appear in Spanish with Original and the English beneath.
  3. When the show caller says "Standby lighting cue 42", read the English line for the cue number. Trust the original for anything that matters.

The stage manager's own screen is untouched: it still reads in the original.

Limits​

  • A reading aid, never a cue call. It bears repeating.
  • A reader can pick a language that few lines can reach. The lines that cannot be translated stay in the original, and the host counts them as failed.
  • Lines in a language Earshot cannot translate from stay in the original.
  • Only the German to English and English to Spanish pairs have been run. DeepL and Claude have not been tried with a real key. See Limits and known behaviour.
