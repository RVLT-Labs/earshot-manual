Display on this device

The display button in the header (the "Aa" at the far right) opens Display on this device. It holds everything about how Earshot looks and reads on the screen in front of you: the language you read in, the theme, the text size, personal keyword alerts, and whether new lines are read aloud by a screen reader.

Every role can change these. They are saved in your browser only. Nothing here changes the show, the host, or anyone else's screen, and a phone and a laptop each keep their own.

The mock show "Spring Tour at Harbour Hall". Not a real show.

Read in​

Read in chooses the language you read the transcript in: Original, or one of the languages the host can translate into, such as "español (Spanish)". While a language is on, the display button shows its code (for example ES).

There is a lot to know about translation, starting with the fact that it is a reading aid and never a cue call. It has its own page: Read in another language.

Theme​

ThemeWhen to use it
DarkThe default. For a dark auditorium, a prompt desk, backstage.
LightFor a bright office, daylight load-ins, or printing a screenshot.
High contrastStronger edges and brighter text. For a dim screen seen from a distance, a washed-out monitor, or low vision.

High contrast theme, mock show. Not a real show.

Channel colours, the red ARMED band and the Safe control keep their meaning in every theme. Nothing in Earshot relies on colour alone: Armed says "ARMED", a draft line is announced as "still speaking", and words Earshot was unsure of are underlined as well as dimmed.

Text size​

Text size goes from 85% to 175%, in steps of 10.

  • Press the minus and plus buttons (Smaller text, Larger text). The number between them is the size now.
  • Reset returns to 100%.

It scales the whole of Earshot on this device, and it scales Focus on top of Focus's own very large type.

A console can also nudge the text size with OSC "font up" and "font down" messages. Those change the host computer's own window only, never a phone or another computer. See OSC addresses.

Read new lines to screen readers​

With Read new lines to screen readers ticked, each new finished line is announced to assistive technology as it arrives. It is on to begin with.

  • Only finished lines are announced, never drafts as they change.
  • Announcements are made while the Feed is open.
  • On a busy show Earshot does not flood the reader: when more than three lines are waiting, it says how many new lines there are instead of reading each one.
  • When you read in another language, the translation is announced, or the original if no translation arrived in time. Never both.
  • If it is still too much to listen to, untick it. The transcript is there to move through at your own pace, and each line is labelled with its channel, the person's name if it has one, and its time.

Personal keyword alerts​

Turn on Flash when my name or keywords are mentioned, then enter your name or phrases in My name or keywords, separated with commas. For example: Jayden, lighting, standby sound.

New spoken or typed lines on your selected channels trigger a five-second banner and a slow flash around the screen. The banner shows the matching keyword, channel and full line for context. Matching ignores case and punctuation and uses whole words: Ann does not match Annette. Drafts, system messages and loaded history do not trigger alerts.

These alerts work while the show is Safe and need no automation. The settings stay in this browser and only this device flashes. Dismiss clears your alert; it does not affect anyone else. With reduced motion enabled on your device, the alert stays steady.

A personal keyword alert in the mock show. Not a real show.

What’s new in Earshot​

The What’s new in Earshot link opens the changelog in a new tab. It lists changes in each release, newest first.

This device: Install app and Sign out​

Under the display settings, a section headed This device appears when there is something to offer:

  • Install app, where the browser can install Earshot. See Installing on a phone.
  • Sign out, for people who signed in with the show password. It asks "Sign out?" and warns "You'll need the password again to rejoin."

On a phone the same two are also under More.

A worked example: one show, three screens​

  • The stage manager's laptop at the prompt desk: Dark, text at 100%.
  • The wall screen in the green room, showing Focus on Show Caller: High contrast, text at 150% so it reads from the sofa.
  • A Spanish-speaking follow-spot operator's phone: Dark, text at 115%, Read in set to "español (Spanish)".

Each was set on that device, once. None of them affects the others, and each is still set the next time that browser opens Earshot.

Limits​

  • The settings live in the browser's storage for the address you opened. Opening Earshot by a different address, in a different browser, or in a private window starts from the defaults. So does clearing the browser's site data.
  • On an iPhone, the Home Screen app and Safari are separate. Signing in on Safari does not carry over to the Home Screen app, so expect to set it up again there.
  • Lane layouts and the Feed's channel filter are kept the same way. See Lanes and Feed.
