Earshot on a phone

Crew use Earshot in a phone's or tablet's browser. There is nothing to install: they open the crew address, join, and read. On a narrow screen the same views are laid out for one hand.

Not tried on real phones and tablets

Nobody has yet tried the join page, installing, or the small-screen layouts on a real phone or tablet, and nobody has confirmed that replayed audio is audible on a phone speaker. The pictures on this page were taken in a desktop browser at phone size. Try your own devices before the show. See Limits and known behaviour.

Getting on​

  1. Join the same network as the Earshot computer.
  2. Open the address from the operator (Setup, Access, Address for the crew), or scan the QR code they show you.
  3. Depending on how the show is set up, you go straight in, type the show password, or use your personal link or code. See The address, and who can connect.
  4. The indicator in the header shows whether the phone is connected to the host (on a wider screen it reads Live). If the phone loses the host it says so, and keeps trying by itself.

Channels​

The side panel of channels does not fit on a phone, so it is behind the Channels button.

The mock show.

  • Channels are listed by group, each with its level meter.
  • Tap a channel to show only that one. Tap more to add them. Tap a group's name to pick all its channels.
  • Show all clears the filter. The cross closes the sheet.
  • "Filtering changes this screen only. Groups are edited in Setup." What you pick here changes nothing for anyone else.

Lanes​

On a phone, Lanes shows one lane at a time with tabs along the top.

The mock show.

"Swipe sideways or use the tabs to change lane". A tab for a lane you are not looking at shows a count of new lines. More on Lanes.

Arming from a phone​

Operators and admins have Arm in the top bar. It works like the desktop control: hold it for about 0.7 seconds, or tap it once and then tap Arm now. Safe is one tap. Read Safe and Armed before you give anyone a phone that can arm.

Put Earshot on the Home Screen​

Open More, then Install app. What happens depends on the device.

iPhone or iPad, in Safari​

The menu shows three steps:

  1. "Tap the Share button in Safari."
  2. "Choose Add to Home Screen."
  3. "Open it from the Home Screen, then ask the operator for a new code. Signing in on Safari does not carry over."
On iPhone, add it first, then join

The Home Screen app does not share Safari's sign-in. If you joined in Safari and then added Earshot to the Home Screen, the app opens signed out, and a QR code that has been used once will not work again. Ask the operator for a new code, or better: add it to the Home Screen first, open it from there, and join then. The join page says the same thing.

Other browsers on iPhone and iPad (Chrome, Firefox, Edge) cannot add Earshot to the Home Screen. Use Safari for this.

Other phones and browsers​

Browsers only let a page install itself as an app when the page is served securely (https). Earshot serves plain http in this build, so other phones and browsers usually cannot install it. The menu says:

"This address can't install apps. Earshot works the same in the browser."

That is all there is to it: use the browser. Add a bookmark if you want a quick way back. Nothing is missing.

If a browser does offer to install it, Install app opens the browser's own install prompt.

Signing out​

If you signed in with the shared password, Sign out is in the More menu and in the display menu. It asks "Sign out?" and says "You'll need the password again to rejoin."

Someone on a personal link has no Sign out: the link is their sign-in. An operator removes them with Revoke.

When the connection drops​

  • The phone shows "Reconnecting" and keeps trying. You do not need to reload.
  • When it reconnects, it catches up on the lines it missed.
  • If the phone cannot reach the host at all, it shows "Can't reach the Earshot computer" and "Check that this device is on the same network as the Earshot computer. This page keeps trying by itself."
  • If the host restarted, people on the shared password must sign in again. Personal links carry on. See When the host restarts.

Tips for crew on phones​

  • Turn the text up. The display button has Text size from 85% to 175%. See Display.
  • Filter to what you need. A followspot operator rarely needs all eight channels. Use Channels.
  • Keep the screen awake using the phone's own settings if you need to glance at it all show. Earshot does not keep a phone awake.
  • It is a reading aid. Listen to the call. A line can be late, and it can be wrong.
