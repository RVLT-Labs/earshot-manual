The shared password

In Password mode there is one password for the whole crew. Everyone who signs in with it becomes an operator: they can read, type, arm the show and run automations. This page covers setting it, what the crew see, the lockouts, and when to use personal links instead.

Who can do this

Only admins set or change the password. Anyone can sign in with it.

Set the password​

  1. Open Setup, Access.
  2. Under Who can connect, pick Password and press Apply. Confirm with Switch to password.
  3. A Password panel appears. Type the password and press Set password.

"At least 8 characters. Share it by voice or message; it is not shown again." A shorter one is refused: "Use at least 8 characters."

When it is saved the panel shows a Password set badge and says "Password set. People can join with it now."

Until a password is set, nobody can join

Switching to Password mode with no password leaves the door shut: "No password set — nobody can join. Only you can connect until you set one." Set the password straight after you switch.

The password itself is never stored. Earshot keeps a scrambled form of it (a hash) on the host, and never sends even that to a browser. If you forget the password, set a new one.

What the crew see​

They open the crew address and get a sign-in page.

The mock host, which calls itself "FOH Rack". Invented, not a real show.

  • The title is "Join" and the name of the Earshot computer, so they can tell they are in the right place.
  • "Enter the show password the operator gave you."
  • Your name (optional): "Shown next to anything you type in the Feed." It is a label people give themselves, not proof of who they are.
  • Join.

A wrong password says "That password is not right. Check it and try again."

Change or clear it​

ButtonEarshot asksWhat happens
Change password"Change the password?" "Everyone who signed in with the old password is signed out. They will need the new one to get back in.""Password changed. Everyone who used the old one is signed out."
Clear password"Clear the password?" "Everyone who signed in with it is signed out, and nobody new can join until you set another.""Password cleared. Nobody can join until you set a new one."

Changing the password is how you remove someone in Password mode. It removes everyone, and the rest of the crew need the new one.

Saving other settings does not sign anyone out. Only changing or clearing the password does, or leaving Password mode.

How long a sign-in lasts​

What happensEffect on someone signed in with the password
They keep using EarshotThey stay signed in. Each use renews it.
They do not use it for 12 hoursThe sign-in expires. They enter the password again.
The host restartsEveryone is signed out and needs the password again. Password sign-ins are kept only in the host's memory. See When the host restarts.
You change or clear the password, or switch to another modeEveryone signed in with it is signed out.
They choose Sign outOnly they are signed out.

Phones can Sign out from the More menu or the display menu. It asks "Sign out?" and says "You'll need the password again to rejoin."

At most 256 password sign-ins can be live at once. A 257th pushes out the oldest.

Wrong tries and lockouts​

Earshot slows down guessing.

  • Five wrong tries from one device lock that device out for 30 seconds.
  • Each further lockout doubles: 1 minute, 2 minutes, 4 minutes, 8 minutes, up to 15 minutes.
  • The phone shows "Too many tries. Try again in m:ss." and counts down, then "You can try again now."
  • A correct password clears the count.
  • People already signed in are not affected. A lockout only stops new sign-ins from that device.

"One device" means one network address. Devices that share an address, for example several phones behind one router or everyone coming through one reverse proxy, are counted together. One person mistyping five times can lock out new sign-ins for the others behind the same address for a short while.

The show-wide brake​

There is one more limit, for the whole show: after 100 wrong password tries within a minute, from all devices together, every new password sign-in is refused for 60 seconds.

This stops someone who keeps changing address from guessing without limit. It has a cost, and you should know it:

  • Someone on your network who deliberately sends about 100 bad guesses a minute can keep new password sign-ins refused for as long as they keep it up.
  • People already signed in, personal links, QR invites and the admin window are not affected. A show in progress carries on.
  • What breaks is a crew member trying to join, or rejoin after a restart, while it is happening.
On a network you do not trust, use personal links

A shared password is one secret that everybody knows, that cannot be taken back from one person, and whose sign-in can be jammed by someone on the network. Personal links have none of those problems: each link is long and unguessable, each can be revoked alone, and they keep working through a host restart. If you must use a password on such a network, make it long.

Example: a password for a one-night show​

  1. Setup, Access, pick Password, Apply, Switch to password.
  2. Type harbour hall tonight (20 characters) and press Set password.
  3. Say it once on the crew channel, with the address from Address for the crew.
  4. Each person opens the address, types the password and their name, and presses Join.
  5. The lighting designer's guest only needs to read. Make them a Viewer personal link. Personal links work in Password mode with their own role, so the guest cannot arm.
  6. After the show, press Clear password. Everyone is signed out and nobody new can join.

What has not been tried​

The sign-in page, like the rest of Earshot on small screens, has not been tried on real phones and tablets. See Limits and known behaviour.
