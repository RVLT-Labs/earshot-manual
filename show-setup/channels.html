Channels

A channel is one thing Earshot listens to: an input on your audio interface, a recording played in for rehearsal, or a place where people only type. This page covers the Channels screen and every setting in the channel editor.

To make many channels at once from an audio interface, use Patch instead. See Patch and channels. Come here afterwards to rename, colour and fine-tune them.

Who can do this

Only admins can open Setup. Everyone else sees "Setup needs admin access". The desktop window and the Admin: address from earshotd are admin. See Roles.

The channel list​

Open Setup, then Channels.

The mock show "Spring Tour at Harbour Hall". Invented channels, not a real show.

Each row shows the channel's name in its colour, where its audio comes from (for example "Simulator: demo/show-caller.wav"), and a live level meter. The buttons on a row are:

ControlWhat it does
The row itselfOpens the channel in the editor on the right.
Up and down arrowsMove the channel up or down. This is the show order, which "next channel" and "previous channel" from a console step through.
DuplicateMakes a copy called "name copy" with a new short name. A copy of a cloud-speech channel is made as a local channel, and the editor says "This copy uses speech on this computer. Choose cloud speech again if you want it." A channel from another Earshot computer cannot be duplicated.
Delete (the bin)Asks "Delete name?" first. See below.
The switchTurns the channel on or off without opening it. A disabled channel does not listen.

Add at the top opens an empty editor. Fill it in and press Create channel.

From another Earshot host adds a channel that another Earshot computer is listening to. That has its own page: Showing another Earshot computer's channels.

If the show has no channels, the list says "No channels yet. Add one here, or tick inputs in Patch to make many at once." with an Open Patch link.

Deleting a channel​

The confirmation says "name will be removed from the show, with its settings. This cannot be undone." It also warns you about two things if they apply:

  • In groups: the channel is removed from those groups.
  • Used by automations: the automations are named, and "will still point at a channel that no longer exists". Open each one and choose another channel, or it will never hear anything.

The channel editor​

Press a channel to open it. The editor has a bar at the bottom with Save changes (or Create channel), Revert, and a note that reads "Unsaved changes" or "Saved". Nothing changes on the host until you save. If you try to leave with unsaved changes, Earshot asks first. If a save fails, the form stays exactly as you left it and the host's message appears above the button.

The mock show. The channel plays a recording through the Simulator, so there is no real audio device here.

At the top is the channel's live status: its level meter and badge. A new channel says "Save the channel to see its live level here."

Name and colour​

SettingNotes
NameWhat everyone reads in the Feed, for example "Show Caller". Required.
SlugThe channel's short name: lower-case letters, digits and single hyphens, like stage-left. Consoles use it in OSC addresses, and automation actions can use it as {{channel.slug}}. Leave it alone on a new channel and the host makes one from the name (the hint shows roughly what it will be). Two channels cannot share one: "Already used by name. Slugs must be unique."
ColourPick a swatch, or type a colour as #rrggbb.
Changing a slug breaks what uses the old one

Once a channel is saved, renaming it does not change its slug. That is deliberate. If you type a new slug yourself, the editor warns: "Used in OSC addresses and automations. Changing it breaks anything that uses the old one." A console sending /earshot/channel/show-caller/select stops working the moment the slug becomes something else.

A name with no letters a to z or digits (for example a name in another script) cannot be turned into a slug. The editor says "This name has no letters or digits a to z, so type a slug yourself, like stage-left."

Audio source​

Source type has three choices.

Source typeWhat it isIts settings
Audio device inputOne input of an audio interface on the host computer.Device (each is listed with its input count, for example "USB Audio Interface (2 in)") and Input number, counted from 1 "as labelled on the device". If another channel already uses that input, the hint says "Input 1 is also used by name." A device that has been unplugged is shown as "(not connected)".
Simulator (WAV file)A recording played in as if it were live. Good for rehearsal and for testing automations with no crew on comms.WAV file path: "A path on the machine running Earshot." Loop the file plays it again and again. With the switch off, the channel goes Idle when the file ends.
Typed text onlyNo audio at all. "This channel has no audio. It only shows messages people type."None.

The Simulator accepts a WAV file of any sample rate and any number of channels. It mixes the file to mono and plays it at normal speed through the same processing a real input gets.

Language and speech engine​

SettingNotes
Language"Detect automatically", or one of the listed languages, or Other… to type a language tag "such as sv or de-CH". Leave it on automatic unless a channel is always in one language and is being heard as another.
EngineLocal (on this machine) uses a speech model installed on the host. Demo (scripted text) plays made-up lines and needs no model. Deepgram (cloud) sends this channel's audio to a company outside the building, and asks you to confirm first. See Cloud and audio.
Speech modelOnly for the local engine ("Only the local engine uses a model."). Default follows the Default speech model chosen under Setup, Models. If none is installed the hint says "No speech model is installed yet. Install one under Models." See Models.
Show words as they are spoken"Partial text appears dimmed, then firms up. Uses more processing." With it off, a line appears only when the person has finished. See draft and final lines.

Audio​

SettingNotes
GainA slider from -24 dB to +24 dB in half-decibel steps. "Trim before speech detection. Most inputs need none." Raise it for a quiet input whose speech is not being picked up.
High-pass filter (100 Hz)"Cuts rumble and handling noise."

Behaviour​

SwitchWhat it does
Enabled"A disabled channel does not listen."
Allow typed messages"People can type lines into this channel." With it off, the Feed's typing box shows the channel as "(no typing)".
Separate and recognise voices on this channelSeparates consecutive speakers and discovers unfamiliar voices automatically. Requires CAM++. On for new audio channels; existing channels keep their previous setting. Give detected voices names in People. See People.
Filter profanityMasks a short list of words in the transcript. It matches exact words only: other forms of a word are not masked unless they are on the list, and a listed word that is also someone's name is masked too. A channel with this on never shows what a changed line was changed from, because that would show the hidden words.
Keep audio for replay"Saves the audio behind each line on the host computer so anyone who can read this channel can replay it." Off by default. See Replay a line's audio and the limits under Cloud and audio.
Shared with other Earshot hostsLets another Earshot computer show this channel. See Showing another Earshot computer's channels.

Faster drafts and timing​

Install Moonshine tiny · English in Setup → Models, then choose it as the channel's Draft speech model for faster English live text. The main speech model still produces finished lines. Drafts may be revised; this option is not a guarantee of accuracy and falls back to the main model if unavailable.

Expand Transcription timing in the Channels list to see median and 95th-percentile timing across this host over the last minute. Draft timing starts after detection; finished-line timing starts at the detected end of speech. Neither includes delivery to the screen. Queue depth shows work waiting to transcribe.

Advanced: speech detection​

Open Advanced: speech detection at the bottom of the editor. "These control when a channel decides someone is speaking. The defaults suit most rooms." Each box shows its default beneath it, and Reset to defaults puts them all back.

SettingDefaultWhat it decides
Sensitivity (0 to 1)0.5How sure the detector must be that a moment of audio is speech. A higher number makes it pickier, so it ignores more noise and may miss quiet speech. A lower number picks up more, including noise.
Pre-roll (ms)500How much audio from just before speech was noticed is kept with the line, so the first word is not clipped.
Hangover (ms)350How long the channel must be quiet before Earshot decides the person has stopped and finishes the line. A longer hangover keeps a slow speaker's pauses in one line, and makes every final line arrive later.
Shortest speech (ms)64How much speech must be heard before it counts as someone talking. Shorter bursts are ignored.
Longest segment (ms)15000The longest a single line may run. Someone who talks without a pause is cut into lines of this length. It cannot be shorter than the shortest speech.

Low latency applies the defaults above and enables live drafts. Comms / noisy feed uses a lower detection threshold and longer lead-in and pause allowance. These are starting points; neither separates overlapping voices or guarantees detection of every word. Existing untouched legacy defaults are upgraded on startup; custom settings are retained.

Change one thing at a time

If a channel misses quiet speech, check the input meter and adjust Gain only if the feed is too quiet. Gain also raises noise; avoid clipping. Save before judging its effect. If it writes lines out of background noise, raise Sensitivity a little (for example from 0.5 to 0.6) and listen again. Cues set to fire on final text wait for the hangover, so a long hangover slows your cues down.

Example: a rehearsal channel from a recording​

You want to try an automation for "Lighting cue 42, go" tonight, and nobody is on comms. The repository carries a few short recordings of computer-made voices in fixtures/audio. One of them, showcaller.wav, says "Standby lighting cue forty two.", "Lighting cue forty two, go.", "Standby sound cue seven and video cue twelve." and "Sound cue seven, go."

  1. Open Setup, Channels, and press Add.
  2. Name: Rehearsal caller. Leave Slug empty. Pick a colour.
  3. Source type: Simulator (WAV file).
  4. WAV file path: the full path to the file on the host computer, for example /Users/you/earshot/fixtures/audio/showcaller.wav.
  5. Switch Loop the file on, so the lines come round again.
  6. Engine: Local (on this machine), with a speech model installed. (Choosing Demo (scripted text) would ignore the recording and play made-up lines.)
  7. Press Create channel.

The level meter starts moving and the lines appear in the Feed. Leave the show Safe and watch Activity: each line that matches an automation is logged as "would have fired". See Testing automations.

When rehearsal is over, switch the channel off with its switch, or delete it.

These recordings are computer-made voices

They are clean speech from a text-to-speech voice. A real party line is noisier, and recognition on it will be worse. See Limits and known behaviour.

Channels from another Earshot computer​

A channel that comes from another Earshot computer is marked with a link icon and "from address". Its editor is much shorter:

  • Audio source is replaced by "Where this channel comes from": the other computer's Address and Port, how it connects, and its link code.
  • It has only Name, Slug, Colour and Enabled. There is no language, engine, gain, typing, voice recognition, profanity filter, saved audio, sharing or speech detection. Those belong to the computer that hears the audio.
  • It has no level meter, because there is no audio here.
  • It says "Lines from another host never fire automations here."

The mock show with three invented linked channels: one working, one whose code was refused, and one that cannot be reached.

Everything about them is on Showing another Earshot computer's channels.
